# Peter Hadorn

I build web apps, automations and pipelines for lead generation, outreach, company data, directories, real estate and research, end to end from collecting the data to monitoring the live product.

**Projects**
- [swissb2b.ch](https://swissb2b.ch): Swiss company data and outreach via postal mailings, built on public sources with AI-assisted fulfillment
- [inmovigia.mx](https://inmovigia.mx): real-estate listings and buyer requests in Playa del Carmen, aggregated from social networks and other sources
- [pilatesyoga.mx](https://pilatesyoga.mx): directory of Pilates and yoga studios in Mexico City, with pricing and review summaries

**Research**
- [Swiss Email Security Report 2026](https://webevolve.ch/studien/schweizer-e-mail-sicherheitsreport/): DNS census of 2.46 million .ch domains ([code](https://github.com/peterhadorn/swiss-email-security-report), DOI [10.5281/zenodo.22116736](https://doi.org/10.5281/zenodo.22116736))
- [Swiss Web Study 2026](https://webevolve.ch/studien/schweizer-web-studie/): CMS, SEO and AI readiness of .ch websites ([code](https://github.com/peterhadorn/swiss-web-report))
